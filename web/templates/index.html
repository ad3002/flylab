How it works

From a sentence to spikes, in five steps.

Each step leaves something you can inspect: the words you wrote, the plan that was checked, the run that happened, the files you keep — and, if you ask, Claude’s hypotheses next to the numbers they came from.

Try it →

  1. 1 / 5

    Describe the experiment

    Write what to stimulate, what to silence and which neurons to watch — in English or Russian. No config files, no code.

  2. 2 / 5

    Claude writes a validated plan

    Claude maps your words onto named neuron groups. A schema validator checks every limit before anything runs; when something is ambiguous, you are asked instead of guessed for.

  3. 3 / 5

    The whole connectome runs

    A Rust leaky integrate-and-fire engine steps all 127,400 neurons through 14.7 million synapses at 0.1 ms resolution — the published model’s equations and constants, nothing simplified away.

  4. 4 / 5

    Compare, then take it with you

    Read the readout rates side by side with the change in Hz, scan the raster, and download a ZIP with the plan, the input events, every spike and a script that replays the run offline.

  5. 5 / 5

    Ask what it might mean

    Claude reads a digest of the run — the numbers FlyLab computed, FlyWire cell annotations and the model’s limits — and proposes hypotheses. Each one cites the numbers it rests on, states its confidence and comes with a follow-up experiment you can run in one click. You can always see exactly what Claude was given.

The connectome

Not a toy network. The fly’s actual wiring.

Every connection in the simulation is a synapse reconstructed by FlyWire from electron microscopy of an adult female Drosophila brain: 127,400 proofread neurons, 14,687,178 synapses, each with its own sign and weight.

Stimulate the labellar sugar receptors and the signal has to find its own way through that wiring to MN9, the motor neuron that extends the proboscis. Nothing is shortcut.

Science

Built on published work, and checked against it.

  1. Model

    Shiu P.K., Sterne G.R., et al. A Drosophila computational brain model reveals sensorimotor processing. Nature 634 (2024)

    The leaky integrate-and-fire model FlyLab implements: same equations, same constants (τm 20 ms, τs 5 ms, threshold −45 mV, 1.8 ms delay), pinned to upstream commit 91bdd1e.

  2. Connectome

    FlyWire Consortium — Dorkenwald S. et al., Neuronal wiring diagram of an adult brain; Schlegel P. et al., Whole-brain annotation and multi-connectome cell typing. Nature 634 (2024)

    Materialization 630 (23 March 2023): completeness and connectivity tables, verified by SHA-256 before every run.

  3. Audit

    Upstream audit of silencing semantics. philshiu/Drosophila_brain_model

    The upstream README says silencing cuts connections to and from a neuron; the executed code zeroes only its outgoing synapses. FlyLab follows what the code does, and says so in every plan.

  4. Reference

    Stimberg M., Brette R., Goodman D.F.M. Brian 2, an intuitive and efficient neural simulator. eLife 8 (2019)

    The Rust engine is checked spike for spike against a Brian2 reference run of the same plan, seed and stimulus.
